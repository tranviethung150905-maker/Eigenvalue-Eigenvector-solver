# Eigenvalue & Eigenvector Solver

A C++ application for calculating eigenvalues and eigenvectors of 2×2 and 3×3 matrices, with support for both real and complex-valued solutions.

## Features

- Calculation of eigenvalues and corresponding eigenvectors for 2×2 and 3×3 matrices
- Support for both real and complex solutions
- Reduced row echelon form for matrix calculations
- Object-oriented matrix operations

## Technologies

- C++
- Object-Oriented Programming (OOP)
- Linear Algebra
